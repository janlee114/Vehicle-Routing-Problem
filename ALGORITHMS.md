If neither source provides a reliable expansion, the acronym is left unresolved rather than guessed.

## Important abbreviation conflicts and review items

- **PSO.py is not Particle Swarm Optimization in its current source.** Its window title says Penguin Search Optimization (PeSOA), while the spreadsheet uses PSO for Particle Swarm Optimization (B15, 1995). Rename the script to avoid confusion, or change the implementation and title if Particle Swarm Optimization was intended.
- **TSA.py and TSA2.py are different methods.** The first is Tabu Search Algorithm (B7, 1986); the second is Tree Seed Algorithm (B229, 2015). The spreadsheet uses TSA for multiple algorithms.
- The spreadsheet reuses abbreviations including ABO, BCO, CA, CCA, COA, CSO, DA, DGO, EFO, GTO, PPA, ROA, SA, SGO, SHO, and WSA. The catalog uses each script's window title to resolve these where possible.
- Nearby spreadsheet entries for ABFTO, AFA, AMO, BROA, CVO, EPCA, ESWSA, FCIA, LSO, and MATCO use different abbreviations. The catalog records those relationships without pretending they are exact abbreviation matches.
- **ABOA, AF-CHSA, SARO, and SM3-MBO** remain unresolved from the current filename/window-title evidence. The possible relationship between SM3-MBO and spreadsheet entry SM^2-MBO needs confirmation.

## Interpreting the repository

- The file list is a catalog of script names, not a claim that every implementation faithfully reproduces every operator from a published paper.
- Most applications model a single depot, customer points, a route visiting all customers, and a return to the depot. The distance objective is Euclidean on the displayed coordinate plane, not road-network distance.
- A common interface does not prove that all implementations use equivalent constraints, initialization, search operators, stopping criteria, or replacement rules. Check each source file before making comparative research claims.
- Update this catalog when repository files are added, renamed, or removed.

## Recommended metadata for a research-grade inventory

For each method, record the canonical name, primary publication, publication year, search representation, initialization, exploration operators, exploitation operators, acceptance/replacement rule, stopping criterion, constraints, evaluation metrics, and validation status.
